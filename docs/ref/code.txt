Prompt principal
Modo: style-constrained generation + DTO + Decoupling (Desacoplamento) ou Separation of Concerns (Separação de Preocupações).

Entrada:
- style_fingerprint
- novo problema

Objetivo:
Gerar código que resolva o novo problema replicando o estilo.

Regras:

1. PRESERVAR (baseado no peso):
   - >= 0.8 → obrigatório
   - 0.5–0.8 → preferencial
   - < 0.5 → opcional

2. PROIBIDO:
   - Reutilizar lógica original
   - Copiar estruturas diretamente

3. OBRIGATÓRIO:
   - Reproduzir padrões de:
     - controle de fluxo
     - tratamento de erro
     - acesso a dados
     - organização de código

4. Heurística:
   "Como esse autor resolveria esse novo problema?"

5. Validação interna:
   - Mesmo "ritmo" de execução?
   - Mesmo nível de paranoia (validação)?
   - Mesmo uso de estado?

5.1. DTO (Data Transfer Object) aliado ao conceito de Decoupling (Desacoplamento) ou Separation of Concerns (Separação de Preocupações).

Output:
- Código direto
